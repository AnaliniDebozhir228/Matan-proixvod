Задание 7.

Задание 8.
9x² + 4y² - 36x + 8y + 4 = 0.
9(x² - 4x) + 4(y² + 2y) = -4.
9(x - 2)² + 4(y + 1)² = 36.
(x - 2)²/4 + (y + 1)²/9 = 1.
Это эллипс с центром (2,-1), вытянутый вдоль оси Oy.
Большая полуось a = 3, малая полуось b = 2.
c = √(9 - 4) = √5.
Фокусы: (2, -1 - √5) и (2, -1 + √5).

Задание 9.

Это гипербола: центр (-1,2), a = 1, b = 2.
Асимптоты: y - 2 = ±2(x + 1).

Задание 12. Спутниковая тарелка.
y = ax². На краю тарелки x = 1 м, глубина y = 0,25 м.
0,25 = a · 1², значит a = 0,25.
Для y = ax² расстояние от вершины до фокуса равно 1/(4a).
1/(4 · 0,25) = 1 м.
Приёмник нужно расположить в 1 м от вершины вдоль оси симметрии.

Задание 13. Поиск источника.
Фокусы: (-5,0) и (5,0), поэтому c = 5.
Модуль разности расстояний равен 6 = 2a, значит a = 3.
b² = c² - a² = 25 - 9 = 16, b = 4.
Уравнение гиперболы: x²/9 - y²/16 = 1.
При x = 6:
36/9 - y²/16 = 1,
y²/16 = 3,
y = ±4√3 ≈ ±6,928.
Проверка для точки (6, 4√3): расстояния до фокусов равны 13 и 7, их разность равна 6. Для нижней точки получается та же разность по модулю.

Задание 14. Проверка точки на эллипсе.
Точка находится внутри эллипса или на нём, если:
(px - x0)²/a² + (py - y0)²/b² ≤ 1.
Реализация приведена в файле Решения.py.

Задание 15. Определение типа кривой.
Вычисляем Δ = B² - 4AC:
Δ > 0 — гипербола;
Δ = 0 — парабола;
Δ < 0 — эллипс, а при B = 0 и A = C — окружность.
Для пяти случаев из задания 6:
3x² + 3y² - 12 = 0 — окружность.
x² + 2y² = 8 — эллипс.
x² - y² = 1 — гипербола.
y = 2x² - 4x + 1 — парабола.
xy = 1 — гипербола.

КРАТКАЯ ШПАРГАЛКА
Окружность: (x - x0)² + (y - y0)² = R².
Эллипс: x²/a² + y²/b² = 1; c² = a² - b²; e = c/a < 1.
Гипербола: x²/a² - y²/b² = 1; c² = a² + b²; e = c/a > 1.
Парабола: y² = 2px; фокус (p/2,0), директриса x = -p/2.
Для сдвинутых кривых координаты заменяются на x - x0 и y - y0.
